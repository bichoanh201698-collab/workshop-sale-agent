# Design system — Workshop Sale Agent deck

Canvas **4480 × 1120 px** (4:1, ultrawide LED wall). Author every value in **real stage pixels** —
`src/js/deck.js` scales the whole stage to whatever screen it lands on. Never use `vw`/`vh`.

## Files
| File | Role | May I edit it? |
|---|---|---|
| `src/css/engine.css` | stage fit, slide transitions, `[data-anim]` primitives | **no** |
| `src/js/deck.js` | navigation, animation replay, overview grid | **no** |
| `src/css/theme.css` | tokens, type scale, layouts, components, decoration | **no** (ask the lead) |
| `src/css/fonts.css` + `assets/fonts/` | self-hosted Be Vietnam Pro + IBM Plex Mono (offline-safe) | no |
| `src/slides/NN-name.html` | one slide each | **yes — this is your work** |
| `index.html` | generated by `./build.sh`, do not hand-edit | no |

Build & preview: `./build.sh` then `./shot.sh <n>` renders slide *n* at full 4480×1120 into the scratchpad.

## Slide contract
Every partial is exactly one `<section>`:

```html
<section class="slide t-ink l-split" data-slide="5" data-title="Fact — 3 con số" id="s05">
  <div class="deco"> …decoration layers… </div>
  <p class="meta">Session 01 <b>·</b> Bối cảnh</p>
  …content…
</section>
```
- `data-slide` = the number in the filename. `data-title` feeds the overview grid (press `O`).
- `id="sNN"` lets you scope slide-specific CSS in a local `<style>` block **inside your own partial**.
  Always scope it (`#s05 .foo{…}`) so nothing leaks to another slide.

## Themes (pick one per slide; alternate for rhythm)
`t-ink` (near-black, default) · `t-ink-2` (lifted charcoal) · `t-paper` (warm off-white) ·
`t-accent` (vermilion flood — reserve for the 3–4 hardest-hitting statements) · `t-mint` (mint flood — reserve for bridges).

Themes redefine `--bg --fg --muted --hair --card`. Always use those tokens, never raw hex.

## Type scale
`.mega` 340 · `.xl` 232 · `.l` 168 · `.h1` 124 · `.h2` 84 · `.h3` 60 · `.body` 48 · `.sm` 38 · `.label` 28 (mono eyebrow) · `.stat .num` 300.
One headline per slide. Body copy is the **spoken line condensed**, never the speaker's full paragraph.

Keyword treatments: `.ac` `.mn` `.am` (accent / mint / amber text), and the swipe underline:
```html
<em class="hl">năng lực tư vấn<i class="hl-bar" data-anim="grow-x" data-delay="900"></i></em>
```
`.hl.fill` = marker fill. `.strike` = crossed out (for "không phải là …" rhetoric).

## Layout archetypes (built for 4:1 — use one, don't invent a new grid)
- `.l-center` — centred single statement. Dividers, conclusions.
- `.l-split` — `.lead` (headline column) + `.payload` (content). The workhorse.
- `.l-triptych` — three equal panels; the canvas's natural rhythm.
- `.l-rail` — a headline band plus a horizontal `.rail` of N cards/steps.
- `.l-stack` — headline band on top, wide content strip below.
- `.l-index` — narrow `.rail-v` eyebrow rail on the left, wide content right.

## Components
`.card` (`.tall` `.hot`) · `.chip` / `.chipset` (`.solid`) · `.stat` (`.a` `.b` `.c` colour variants, `.num` + `.den` + `.cap`) ·
`.steps` (auto-numbered `01 02 03`) · `.qs` (question list) · `.kvgrid` + `.kv` · `.thread` + `.bub` (`.me` `.agent`, with `.who`) ·
`.arrow` (handoff) · `.speaker` (`.av` `.nm` `.ro`) · `.pulse` · `.typing` · `.meta`.

The **chat bubble** is the deck's recurring motif — the whole workshop is about a conversation. Reach for it often.

## Decoration — inside `<div class="deco">…</div>` only
`.deco-grid` (24-col hairlines) · `.deco-orb` (`.mint` `.amber`; position it inline, it drifts on its own) ·
`.deco-noise` (grain) · `.deco-marquee` (keyword ticker — brilliant across 4480px, use on dividers) ·
`.deco-dots` · `.deco-frame` · `.deco-bar` (`.top` `.bottom` `.left`).

Two or three layers max. Decoration supports the sentence; it never competes with it.

## Motion
Put `data-anim="<name>"` on anything that should enter. It replays every time the slide is shown.
`fade up up-sm down left right scale scale-out blur wipe-r wipe-l wipe-u mask-up track grow-x grow-y`

- `data-delay="600"` (ms, explicit) or `data-stagger="120"` on a parent for automatic sequencing.
- `data-dur="1400"` overrides duration.
- `mask-up` needs a `.mask` wrapper: `<span class="mask"><span style="display:block" data-anim="mask-up">…</span></span>`
- **Budget: the whole slide must finish landing inside ~1.8 s.** A speaker is talking over this.
- Order the reveal the way the speaker says it: eyebrow → headline → evidence → punchline.

## Rules
1. Respect the safe area (`--safe-x` 200px, `--safe-y` 104px). Press `G` in the deck to see it.
2. **Fill the width.** A 4:1 stage punishes a centred 1200px column — dead air on both sides reads as a mistake. Use the full 4080px of usable width, or deliberately centre with real presence.
3. Nothing may overflow 1120px tall. Check with `./shot.sh`.
4. **Vietnamese diacritics — read this twice.** Two separate hazards:
   - *Clipping:* never let `overflow:hidden` (incl. `.mask`) cut a diacritic. Masks need `padding-top:.14em; margin-top:-.14em`.
   - *Collision:* a dot-below on line 1 (ạ ộ ệ ặ ụ) lands in line 2's tone-mark zone at tight leading — "Hãy tạo" renders as "Hãy tao". Single-line display type may go as tight as .86, but **any multi-line display type needs line-height ≥ 1.04**. Check the render, not the number.
5. No em-dash-free rewriting of the speaker's words — condense, don't paraphrase into something they didn't say.
6. No external assets, CDNs, or images. Everything is CSS/SVG.
